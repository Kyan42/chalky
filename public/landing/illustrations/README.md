# Chalky illustration pack

Seven original, scalable SVG illustrations for the Chalky landing page: rocks, plant, orbit, book, conversation, chalk, and neuron. Transparent backgrounds. Hand-drawn charcoal outlines and angular mustard fills connect the illustrations to the existing Chalky identity.

Palette: paper #F8F6EF, ink #292820, mustard #C3932B, pale gold #E7C96F, sage #A0A675.

Typography: existing local Instrument Serif regular/italic and Instrument Sans regular/medium. Font licenses are in public/fonts/OFL.txt.

Existing brand files remain in public/brand and public/mascot. The landing page reuses the original logo and animated chalk-in-hand mascot without modifying them.
